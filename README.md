# 🍅 Pomodoro Timer

A cozy and minimalist Pomodoro timer built with HTML, CSS, and JavaScript.

This project was developed as the final project for the Codédex JavaScript course. The goal was to create a productivity tool that helps users stay focused using the Pomodoro Technique while providing a friendly and visually appealing experience.

## ✨ Features

- Select between **2 and 10 work intervals**
- **25-minute work sessions** and **5-minute break sessions**
- Start, pause, and reset controls
- Automatic transition between **Work Mode 🍅** and **Break Mode ☕**
- Session progress tracking
- Automatic **Session Complete! ⭐** state when all intervals are finished
- Circular progress indicator
- Responsive design
- Cute pastel aesthetic with a custom tomato pattern background

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🎯 How It Works

1. Select the number of work intervals for the session.
2. Press **Start** to begin the timer.
3. The application alternates between:
   - 🍅 Work sessions
   - ☕ Break sessions
4. After completing all selected work intervals, the timer displays a **Session Complete! ⭐** message.
